## Лабораторная работа №2
### Класс итератор с гибкой настройкой и удобным применением.

```python
class CountDown:
    def __init__(self, start):
        self.count = start + 1

    def __iter__(self):
        return self

    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count

if __name__ == '__main__':
    counter = CountDown(5)
    for i in counter:
        print(i)
```
### Результат.
![Меню](https://github.com/dermhl/Prog/blob/tema_11/pic/lab_2.png)

## Выводы

Этот класс реализует итератор, который выполняет обратный отсчет от заданного числа до нуля:

- class CountDown: — определяет класс для обратного отсчёта.
- __init__(self, start) — инициализирует счётчик со значением start + 1.
- __iter__(self) — возвращает сам объект-итератор.
- __next__(self) — уменьшает счётчик на 1; при достижении < 0 делает StopIteration.
- for i in counter: — перебирает объект CountDown, выводя значения от start до 0.

## Лабораторная работа №3
### Генератор списка.

```python
a = [i ** 2 for i in range(1,5)]

print('a - ', a)
for i in a:
    print(i)

print('iter(a) - ', iter(a))
for i in a:
    print(i)
```
### Результат.
![Меню](https://github.com/dermhl/Prog/blob/tema_11/pic/lab_3.png)

## Выводы

Этот код создает список квадратичных чисел и демонстрирует работу с ним через цикл и функцию iter():

- a = [i ** 2 for i in range(1,5)] — создаёт список квадратов чисел 1,2,3,4 → [1,4,9,16].
- print('a - ', a) — выводит весь список.
- Первый for i in a: — поэлементно выводит квадраты.
- iter(a) — создаёт итератор по списку (тип list_iterator).
- Второй for i in a: — повторно выводит те же элементы из списка, так как a — список, который можно перебирать многократно.

## Лабораторная работа №5
### Такой же счетчик, как и в первом задании, только это генератор и использует yield.

```python
def countdown(count):
    while count >= 0:
        yield count
        count -= 1

if __name__ == '__main__':
    counter = countdown(5)
    for i  in counter:
        print(i)
```
### Результат.
![Меню](https://github.com/dermhl/Prog/blob/tema_11/pic/lab_5.png)

## Выводы

Эта функция-генератор выполняет обратный отсчет от заданного числа и позволяет перебирать значения по одному: 

- def countdown(count): — определяет функцию-генератор для обратного отсчёта.
- yield count — возвращает текущее значение и приостанавливает выполнение.
- countdown(5) — возвращает генератор, который выдаёт числа 5,4,3,2,1,0.
- Цикл for i in counter: — выводит каждое значение из генератора, реализуя обратный отсчёт.

## Самостоятельная работа №1
### Вас никак не могут оставить числа Фибоначчи, очень уж они вас заинтересовали. Изучив новые возможности Python, вы решили реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет в оперативной памяти огромную последовательность, а дает возможность “доставать” промежуточные результаты по одному).

```python
def fib(n):
    a, b = 1, 1
    for i in range(n):
        yield a
        a, b = b, a + b

if __name__ == "__main__":
    n = int(input("Введите количество чисел Фибоначчи: "))
    for num in fib(n):
        print(num)
```
### Результат.
![Меню](https://github.com/dermhl/Prog/blob/tema_11/pic/sam_1.png)

## Выводы

Эта программа генерирует последовательность чисел Фибоначчи заданной длины:

- def fib(n): — определяет функцию-генератор для получения n чисел Фибоначчи.
- yield a — возвращает текущее число Фибоначчи и приостанавливает выполнение функции до следующего вызова.
- for num in fib(n): print(num) — перебирает и выводит по очереди все сгенерированные числа Фибоначчи.
- n = int(input(...)) — запрашивает у пользователя количество чисел, которые нужно сгенерировать.
