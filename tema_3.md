## Лабораторная работа №1
### Создайте две переменные, значение которых будете вводить через консоль. Также составьте условие, в котором созданные ранее переменные будут сравниваться, если условие выполняется, то выведете в консоль «Выполняется», если нет, то «Не выполняется».

```python
one = int(input('Введите значение первой переменной: '))
two = int(input('Введите значение второй переменной: '))
if one >= two:
    print('Выполняется')
else:
    print('Не выполняется')
```
### Результат.
![Меню](https://github.com/dermhl/Prog/blob/tema_3/pic/лаба_1.png)

## Выводы

Эта программа сравнивает две переменные и выводит сообщение о том, выполняется ли условие one >= two:

1. one = int(input(...)) — запрашивают у пользователя ввод значения для первой переменной, преобразуют его из строки в целое число и сохраняют в переменную one.
2. two = int(input(...)) — аналогично для второй переменной.
3. if one >= two: — сравнивают два числа: если значение one больше или равно значению two.
4. print('Выполняется') — выводится, если условие истинно (первая переменная больше или равна второй).
5. else: print('Не выполняется') — в случае если условие ложно, выводится one меньше two.

### Напишите программу, в которой циклом for значения переменной i будут меняться от 0 до 10 и посмотрите, как разные виды сравнений и операций работают в цикле.
```python
for i in range(10):
    print('i =', i)
    if i==0:
        i+=2
    if i==1:
        continue
    if i ==2 or i==3:
        print('Переменная равна 2 или 3')
    elif i in [4,5,6]:
        print('Переменная равна 4,5 или 6')
```

В этом коде цикл перебирает числа, выводит их, при определённых условиях выводит сообщения, и останавливается, когда i достигнет значения, при котором срабатывает break:

1. 'for i in range(10):' — цикл перебирает значения i от 0 до 9.

6. 'elif i in [4, 5, 6]:' — при i=4, i=5, или i=6, выводится сообщение, что переменная равна 4, 5 или 6.
7. else: — при любом другом i (от 7 и выше): break — прерывает выполнение цикла.

## Самостоятельная работа работа №5
### Составьте программу из фрагментов кода.

```python
counter = 0
values = [0, 2, 4, 6, 8, 10]
string = 'hello'
while counter != 11:
    if counter in values:
        string = 'hello world'
    else:
        string = 'hello'
    print(string)
    counter += 1
```
